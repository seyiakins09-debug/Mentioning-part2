# SEY GAMERZ — MENTIONING

## Render
Build Command:
npm install

Start Command:
npm start

The game uses Socket.IO for live rooms and multiplayer synchronization.
Questions are built in: 30 sets × 10 questions = 300 questions.

Host:
1. Create a room.
2. Share the 6-character room code.
3. Wait for players.
4. Start the game.
5. Review submitted answers.
6. Click CORRECT +200 XP for the winner.
7. Click NEXT QUESTION.

Player:
1. Join with name + room code.
2. Submit one answer per question.
3. Wait for the host to judge.
